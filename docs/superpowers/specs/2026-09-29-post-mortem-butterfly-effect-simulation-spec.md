# 《东汉末年汉灵帝》身后因果网与历史蝴蝶效应推演架构设计

## 一、 顶层设计哲学与底层唯物史观

1. **历史必然性与偶然性的辩证统一**：
   - 生产力水平不足、庄园经济隐匿人口、土地兼并加剧与长期沉重剥削，决定了**“农民大起义（黄巾之乱）必然爆发”**。
   - 农民阶级受限于阶级局限性、组织松散与缺乏科学建政纲领，**绝不可能建立稳固的全国政权**。
   - 黄巾之乱的结局走向必然是：**被世家豪强军阀逐个击破、收编裹挟（如曹操收青州兵、公孙瓒击破青徐黄巾、袁绍收降黑山军），由此导致地方军阀与世家豪强权柄空前膨胀，中央皇权彻底沦为军阀争霸的政治工具。**
   - 玩家作为汉灵帝，无法凭空消除黄巾之乱，**唯一能干预的是爆发的【烈度规模】与朝廷应对危机时所付出的【制度代价】**。

2. **三国核心支点人物与因果依赖树（Pivotal Dependency Graph）**：
   - **曹魏线**：曹操为核心枭雄。若曹操未有反心（被朝廷重用且皇权稳固）或未脱离洛阳中枢，则曹魏割据不成立。
   - **蜀汉线**：
     * 支点一（刘备起家）：若黄巾规模极小且中央不放军权，刘备无功起兵，无法形成初始核心班底；
     * 支点二（诸葛亮与赤壁）：若北方军阀南下而诸葛亮未出山，江东张昭等投降派占据压倒优势，孙吴降曹（或与曹魏瓜分荆州），赤壁之战消失；
     * 支点三（庞统取蜀）：刘备得荆州若无庞统献策夺取西川刘璋，刘备困守荆南，蜀汉政权不成立。
   - **东吴线**：
     * 支点一（洛阳之乱与玉玺）：洛阳若未大乱，孙坚得不到传国玉玺，孙策无筹码向袁术借兵三千开辟江东；
     * 支点二（袁术压制）：若袁术未称帝败亡、生前死死压制孙策，孙策无法自立；
     * 支点三（孙策与孙权交接）：孙策若未遇刺，其激进北伐路线主导江东；若遇刺身亡，孙权接掌大权转为守成与士族共治。

## 二、 核心蝴蝶事件推演矩阵

```
                                ┌── 1. 小规模暴动 (民心稳定/提前度田) ──> 中央军速平，不放军权 ──> 三国萌芽被掐灭 (曹刘孙无私兵)
                                │
【黄巾之乱】(184年4月必然爆发) ──┼── 2. 史实八州并起 (民心30~40) ────> 下放募兵权/废史立牧 ──> 世家军阀崛起，激活三国支点网
                                │
                                └── 3. 烈度失控 (民心<20/大肆搜刮) ────> 破虎牢关，皇权归零 ──> 军阀彻底裹挟黄巾，皇权沦为傀儡工具
```

### 1. 【黄巾之乱·爆发烈度与应对代价】
- **因果规则**：
  - **规模小（中央速平）**：仅冀州/青州数郡叛乱。中央西园禁卫军与北军直接平定，严禁地方私募。刘备无军功起家，曹操仅为洛阳骑都尉/典军校尉无家族私兵，孙坚按部就班升迁。三国初始武装力量无法成型。
  - **规模中（史实下放军权）**：朝廷下放募兵权并设州牧。军阀收编黄巾（如青州兵），豪强地盘化，激活三国争霸支点。
  - **规模大（中央失控破京）**：黄巾直逼京畿，但因其自身局限性迅速被地方军阀（袁绍、曹操、公孙瓒等）以“勤王”为名收割裹挟。皇权彻底丧失控制力，提前沦为军阀争霸的旗号。

### 2. 【189年洛阳权力交接与董卓进京】
- **因果规则**：
  - 灵帝生前若兵权归于西园军、削弱何进/袁氏，或灵帝延寿活过189年：
    * 董卓无借口进京，被阻于凉州；
    * 洛阳未焚，少府完好，传国玉玺不失；
    * 关东诸侯失去“讨董”大义，无法公然裂土。

### 3. 【孙坚玉玺与江东基业】
- **因果规则**：
  - 洛阳未乱 $\rightarrow$ 孙坚无玉玺 $\rightarrow$ 孙策无借兵筹码 $\rightarrow$ 孙策无法强渡长江 $\rightarrow$ 江东沦为四大家族（顾陆朱张）割据自守。
  - 洛阳大乱 $\rightarrow$ 孙坚得玉玺 $\rightarrow$ 袁术死死压制孙策（若袁术未灭）或 孙策借兵渡江成霸业。

### 4. 【荆襄博弈、诸葛亮与赤壁之战】
- **因果规则**：
  - 北方势力统一黄河流域南下：
    * 若诸葛亮在刘备麾下且促成孙刘联盟 $\rightarrow$ 赤壁火攻，三分天下维持平衡；
    * 若诸葛亮未出山 / 已入朝为官 $\rightarrow$ 江东张昭等投降派主导孙吴迎降，南北迅速归一。

### 5. 【庞统献策与西川益州归属】
- **因果规则**：
  - 刘备占据荆州后：
    * 若得庞统献上中下三策 $\rightarrow$ 夺取益州刘璋，蜀汉政权正式鼎立；
    * 若无庞统 / 益州被朝廷直接控制 $\rightarrow$ 刘备困守荆州，无法入蜀，演变为南北对峙或曹吴争雄。

## 三、 天子身后推演状态机模型 (PostMortem State Machine)

灵帝驾崩（任意年份死亡）时，系统提取当时的全局世界快照：
$$\text{Snapshot} = \{\text{Year}, \text{ImperialPower}, \text{Treasury}, \text{PopularSupport}, \text{WestGardenArmy}, \text{StateLandRatio}, \text{Provinces}, \text{NpcStates}\}$$

推演引擎依次执行以下四个决议链：
1. **阶段一：黄巾余波与军阀收割判定**（计算世家兼并率与军阀兵力规模）；
2. **阶段二：洛阳中枢交接判定**（稳定继承 vs 权臣篡夺 vs 董卓入京）；
3. **阶段三：三国核心支点推演**（曹操走向、刘备与诸葛庞统、孙策玉玺与江东）；
4. **阶段四：生成《后汉书·身后五十年大势纪》**（动态生成图文画卷，赋予天子庙号、谥号与历史定论）。
