# 帝王权术财政博弈与世家察举荐辟核心系统规划 (Imperial Power, Confiscation & Recruitment Spec)

> **设计背景**：汉灵帝统治的核心矛盾在于“财权-军权-皇权”的三角平衡，以及“寒门/宦官/世家大族”的权力再分配。将机械化的流程事件转变为高自由度、高代价取舍的帝王心术模拟系统。

---

## 一、 核心闭环：财政四角天平与皇权控制力模型

```
                      ┌────────────────────────┐
                      │    皇权控制力 (0~100)  │
                      └───────────▲────────────┘
                                  │ +皇权 (立威/军心归附)
             ┌────────────────────┼────────────────────┐
             │                    │                    │
    ┌────────┴────────┐  ┌────────┴────────┐  ┌────────┴────────┐
    │ 抄家没收 (查办) │  │ 犒赏三军 (发饷) │  │ 苛捐杂税 (加征) │
    └────────┬────────┘  └────────┬────────┘  └────────┬────────┘
             │ +国库暴富          │ -国库金帛          │ +每旬税收
             │ +天下民心          │ +禁军士气          │ -天下民心
             │ -关联世家忠诚      │ (士气<30触发兵变)  │ (民心<40黄巾再起)
```

### 1. 抄家断案与皇权立威机制 (`ConfiscationSystem`)
- **正向收益**：
  - **国库/内库暴增**：瞬间缴获该贪官/世家隐匿一世之私产（金帛、粮食、田产庄园）；
  - **皇权控制力提升**：以霹雳雷霆手段整肃朝纲，天子威严立显（皇权 $+5 \sim +10$）；
  - **民心大振**：严惩巨贪豪强，升斗小民拍手称快（民心 $+10 \sim +15$）。
- **反向代价（关联网络惩罚）**：
  - **世家关联网络震荡**：并非全图盲目减忠诚，而是根据**派系/宗族关系网（如袁氏门生故吏、弘农杨氏、宦官外戚亲党）**，与被查办者有同党、师生、姻亲关系的官员忠诚度暴跌（$-20 \sim -30$）；
  - **官僚人人自危**：非关联中立官员忠诚微跌（$-5$），若连续抄家导致全朝野忠诚 $<30$，触发【朝臣罢朝 / 勾结外藩诸侯 / 甚至毒鸩刺驾】。

### 2. 军饷发放与禁军哗变机制 (`MilitaryPayrollEngine`)
- **按旬常规军饷**：禁军规模越大，每旬基础开销越重；
- **内库犒赏（打赏军队）**：
  - 天子自掏内帑大赏三军 $\implies$ 西园禁军士气暴涨（Morale 100），将士愿为天子死节，**直接提升皇权控制力（皇权 $+5 \sim +10$）**；
- **欠饷断炊与兵变惩罚**：
  - 国库赤字或欠饷 $\implies$ 士气每旬暴跌；
  - 当士气 $< 30$ 时：触发**【禁军哗变 / 兵谏洛阳】**，禁军军官劫掠府库或扣押天子。

## 二、 世家察举与人才荐辟系统 (`TalentNominationSystem`)

> 汉代取士以“察举制（举孝廉、茂才）”与“公府辟召”为主，名额掌握在各大世家门阀与三公手中。

```
[各大世家名门 (汝南袁氏/弘农杨氏/颍川荀氏/谯县曹氏)]
                        ↓ 每岁/每季推荐
            [孝廉与名士人才候选名册]
                        ↓
            [天子御批选择性任命]
             /               \
[获得任用的世家]            [被搁置/驳回的世家]
  • 该世家好感/忠诚 ↑          • 该世家心怀怨望/忠诚 ↓
  • 该人才入朝效力/任太守      • 埋下外逃投奔关东诸侯隐患
  • 朝堂该派系势力扩张         • 触发世家非议天子“昏庸背道”
```

### 1. 核心属性与实体设计
- **世家门阀实体 (`AristocratFamily`)**：
  - `FamilyId`（如 `ru_nan_yuan` 汝南袁氏, `hong_nong_yang` 弘农杨氏, `ying_chuan_xun` 颍川荀氏, `qiao_xian_cao` 谯县曹氏等）；
  - `Prestige`（世家声望：影响举荐人才的初始属性与天下名士向心力）；
  - `Loyalty`（世家对汉室忠诚度）；
  - `Power`（朝堂与地方门生故吏规模）；
  - `AffiliatedNpcIds`（该世家关联的朝臣与武将清单）。

### 2. 察举推荐与任命博弈规则
1. **岁举孝廉**：每逢岁首或特定季节，各大世家向尚书台呈递《举荐孝廉奏折》；
2. **天子权衡抉择**：
   - **重用该世家人才**：将该人才拜为议郎、御史或外放实权太守 $\implies$ 该世家忠诚大涨（$+15$），获得高智谋/政略臣工；**代价**：朝堂上该门阀力量膨胀，可能反噬皇权；
   - **平衡压制（任命寒门/宦官门生）**：驳回世家子弟，拔擢寒门才俊 $\implies$ 提升皇权自主性，但被驳回的名门望族忠诚下跌（$-10 \sim -20$）；
   - **冷落名士的后果**：被朝廷长期冷落的高属性名士（如郭嘉、荀彧、陈宫、贾诩等），会心怀怨望出走洛阳，流向关东诸侯（曹操、袁绍、刘备）幕府，反哺增强诸侯势力！
